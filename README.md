# dao-budget-simulator

## Frontend TV3

Để mở web ngay bằng fixture: `cd frontend`, `npm ci`, `npm run dev`, rồi mở URL Vite in trong terminal (thường là `http://localhost:5173/`). Không cần backend hoặc ví để xem giao diện. Hướng dẫn các màn hình, cách hoạt động, cấu hình deployment/API thật và lệnh kiểm tra nằm trong [frontend/README.md](frontend/README.md).
