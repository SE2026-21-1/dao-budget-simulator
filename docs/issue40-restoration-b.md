## Safety boundaries

Process checks compare PID, PPID/legitimate reparenting, kernel start ticks, boot ID, executable and exact argv/run markers; listener checks inspect socket inodes and PID fds without sending packets. Identity is not a tamper-proof security boundary against the same OS owner; normal local check/use races are narrowed, not an atomic kernel-level network lock. Foreign/missing/wildcard listeners fail closed and are never killed. If ownership cannot be established on the shared transport, remain HOLD and request an independently owned receiver through the reviewers; do not repair shared infrastructure.
