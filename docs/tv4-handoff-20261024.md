## Publish và bước GitHub còn lại

HTTPS push thiếu credential nhưng SSH agent hiện có đã push thành công; không đổi origin, không force-push. Có thể dùng đúng URL SSH của repository khi origin vẫn là HTTPS:

```bash
git -c core.sshCommand='ssh -o BatchMode=yes -o StrictHostKeyChecking=yes -o ConnectTimeout=15' \
  push git@github.com:SE2026-21-1/dao-budget-simulator.git \
  refs/heads/feature/tv4-operation:refs/heads/feature/tv4-operation
```

SSH git authentication không thay GitHub API credential. Khi có quyền API hoặc đăng nhập GitHub UI, cập nhật PR#21 và ba issue bằng nội dung trên, request đúng reviewer và đọc CI của chính revision tương ứng. Không reset/force-push, tự merge/approve hoặc đóng gate BE07/testnet. README AD-064 và tài liệu chưa tracked vẫn là thay đổi cục bộ riêng.
